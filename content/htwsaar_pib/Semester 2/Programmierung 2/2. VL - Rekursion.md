### Heap Space :

- dynamischer [[Speicher]] Objekte und referenzvariablen wenn Sie nicht lokal deklariert werden

  

```Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
      
     System.out.println(calculateSum(300)); 
  }
  
        public static int calculateSum( int n ) {
        
        int sum = 0 ;
        
        for ( int i = n ; i > 0 ; i-- ){
          
          sum += i ; 
          
          
        }
        
        
        return sum;
        
}
```
