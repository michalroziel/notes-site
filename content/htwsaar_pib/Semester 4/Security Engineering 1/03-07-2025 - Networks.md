> ## Network Configuration - NIC Device + IP address
> 
> ### Was ist NIC ?
> 
> - NIC : Network Interface Card - ==Also eine HardWare oder virtuelle Karte die den Rechner mit einem Netzwerk verbindet.==
> 
> - must be recognized by the Kernel
> 
> - is available under a name like : `eth0`, `eth1` etc.
> 
>   
> 
> ### IP Adresse ? (broadcast, netmask)
> 
> - Muss via `ifconfig` konfiguriert werden
>     
>     - Beispiel Linux :
>     
>     ```Bash
>     ifconfig eth0 134.96.216.97 netmask 255.255.255.0 \
>     broadcast 134.96.216.255
>     ```
>     
> 
> ## Network Configuration - Routing
> 
> Ein _**Default GateWay**_ ist ein Router, an den unser Computer alle Datenpakete schickt, für die er kein spezielles Routing kennt.
> 
> Wenn Ziel nicht bekannt → _**Default GateWay**_
> 
> ### Adding a default GateWay :
> 
> `example route add default gw 134.96.216.1 (Linux)`
> 
> > [!important]
> > 
> > Mit dem Kommando `netstat -rn` kann man die eigene Routing Tabelle anzeigen lassen.
> 
> ## Network Configuration - Wozu DNS ?
> 
> Ohne DNS hätten wir nur IP Adressen von Computern, aber mit einem _**DNS LookUp**_ sind wir in der Lage eine Domain wie `[example.com](http://example.com)` mit Ihrer IP Adresse zu verbinden.
> 
> > [!important]
> > 
> > DNS ist also das **Telefonbuch des Internets**: Name → Nummer (Domain → IP).
> 
> ### Konfiguration unter UNIX/Linux
> 
> - Datei `**/etc/resolv.conf**` enthält die Einstellungen:
>     
>     - `nameserver` → sagt, welcher DNS-Server befragt wird (z. B. `8.8.8.8` für Google DNS).
>     
>     - `search` → Domain-Suffix, das automatisch ergänzt wird (z. B. `htwsaar.de`, sodass `www-crypto` automatisch zu `www-crypto.htwsaar.de` wird).
