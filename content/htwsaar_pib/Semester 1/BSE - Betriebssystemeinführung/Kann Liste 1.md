  

## Was ist ein Betriebssystem ?

  

- Zusammenfassung von Software- und Hardware komponenten, sodass es als Benutzerfreundliche Oberfläche verwendet werden kann

  

## Weiß, welche grundlegende Aufgaben ein Betriebssystem erledigt

- Verbirgt die Komplexität der Realen Maschine

- Bereitstellung einer Benutzerschnittstelle

- Prozess und [[Speicher]] Verwaltung

- Koordination von Prozessen

- Verfolgung von Schutzstrategien bei Resourcenbereitstellung

## Was ist das Schichtenmodell von LINUX / UNIX

- Ein Computer besteht aus drei Teilen :
    
    1. Hardware - Komponenten ( Prozessor , [[Speicher]] , Disk )
    
    1. BetriebssystemKern - verwaltet Resources, [[Speicher]], Systemaufrufe → Generell für Kommunikation zuständig
    
    1. Softwares - Open Source Programme
    

  

## Weiß, was CLI und GUI bedeuten

- GUI → Graphical User Interface, ( Graphische BenutzerOberfläche ) für einfache Bedienung von Software

- CLI → Command Line Interface → Präzise Steuerung durchs präzise Eingaben von Befehlen
    
    - Ohne GUI

## Skalierbar vs. Portabel

- **Portabel** :
    
    - Das Betriebssystem kann auf verschiedenen Geräten ausgeführt werden, ohner Änderungen im Code am Kern des Systems machen zu müssen.
    

- **Skalierbar** :
    
    - Die Fähigkeit eines BS mit steigender Arbeitslast angemessen umzugehen → Windows Server , Linux Server
